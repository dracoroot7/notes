# Agent Configuration for Notes Repository

This repository serves as a technical knowledge base and learning library. Agent configurations and instructions have been modularized into separate dedicated documents in the [`agent/`](agent/) directory.

## Table of Contents & Modular Rules

- **[Project Overview](agent/overview.md)**: Technical scope, repository objectives, and core domain knowledge.
- **[Style & Formatting](agent/style-and-formatting.md)**: Presentation guidelines, clarity, LaTeX math formulas, code block standards, and markdown structure.
- **[Topic Areas](agent/topic-areas.md)**: Key areas of technical expertise (Linux/Shell, Color Science, Data Analytics, Modal Editors, Python, Business/Media Law, Learning Roadmaps).
- **[Agent Instructions](agent/instructions.md)**: Workflow guidelines, verification steps, dynamic range & concept explanations, and file organization rules.
- **[Git & Commit Guidelines](agent/git-guidelines.md)**: Conventional Commits standards, scope rules, co-authored-by rules, and commit message examples.

---

## Quick Reference Summary

- **Relative URIs**: Always use relative URIs/paths for internal cross-references (e.g. `[Title](filename.md)`).
- **Code & Math**: Provide working code snippets and standard LaTeX syntax (`$...$` / `$$...$$`).
- **Commits**: Follow Conventional Commits format (`type(scope): description`) without `Co-authored-by` trailers.
