# Agent Instructions & File Organization

## Agent Workflow Guidelines
When working on notes in this repository:
1. Verify code examples, shell commands, and mathematical formulas for correctness.
2. Keep examples concise but complete.
3. Explain why something works, not just how (e.g., why logarithmic encoding preserves dynamic range).
4. Include common pitfalls and troubleshooting tips.
5. Cross-reference related concepts within the repository using relative URIs (`[Title](relative-path.md)`).
6. Maintain consistent formatting across all note files.

## File Organization Rules
- **Root-level files**: General reference notes and topic courses.
- **Category subdirectories**: Grouped by topic area when added.
- **Self-contained notes**: Each note should be self-contained but cross-referenced via relative links.
