# Topic Areas & Expertise

Agents working in this repo should maintain expertise across:

- **Linux & Shell Workflows**: System administration, user/process management, Bash scripting, `tmux`, and Unix power tools.
- **Color Science & Imaging Mathematics**: Logarithmic transfer functions, camera log curves (S-Log3, LogC3, Apple Log), AgX tone mapping pipelines, linear vs. perceptual light dynamics.
- **Data Analytics & CLI Wrangling**: Text stream manipulation (`grep`, `sed`, `awk`), structured CLI data tools (`jq`, `csvkit`), and applied statistics.
- **Modal Editors & Workflows**: Helix editor configuration/navigation, Neovim/Vim, distraction-free writing systems.
- **Modern Python Development**: Modern Python features (Python 3.8–3.13+), type hinting, structural pattern matching, async programming.
- **Business & Media Law**: Podcasting/creator legal frameworks, LLC structures, copyright, trademark, and contractor agreements.
- **Structured Learning Roadmaps**: Actionable, phased study plans with clear goals and milestones.
